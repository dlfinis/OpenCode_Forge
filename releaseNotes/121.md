## 1.2.1

### Improvements

- **Smaller distribution**: the plugin archive no longer bundles `kotlin-stdlib`. It uses the copy the IDE already provides, which drops the download from 3.2 MB to 1.9 MB and removes a second Kotlin runtime from the plugin classloader.
- **Build toolchain refreshed**: Gradle 9.9.0, IntelliJ Platform Gradle Plugin 2.20.0, Kotlin 2.2.20, OkHttp 5.5.1, Gson 2.14.0.
- **Removed a dead dependency**: `okhttp-sse` was declared but never used — the SSE listener reads the response body directly. It is gone from the distribution.
- **Clear message for OpenCode v1**: a v1 server answers HTTP but has no `/api/info`, so it used to be offered as an "unverified service" and connecting produced a session where every call returned 404. The plugin now probes `/global/health` once, recognises v1, and says so instead of pretending to connect. v1 is not supported; upgrade the CLI.

### Identity

- **Name and id**: published as **OpenCode Forge** under `io.github.dlfinis.opencode.forge`. The original id `ai.opencode.ide.jetbrains` belongs to LaiZhou's Marketplace account, so a fork cannot publish under it, and two archives sharing an id would replace each other on install. This build therefore appears as a **separate plugin entry** and does not upgrade the original in place.
- The name is deliberately distinct: the Marketplace already lists three entries named "OpenCode UI", and a fourth near-identical name would be harder to find, not easier. Lineage is stated in the description, the README and the credits.

### Fixes

- **Accept no longer fails for gitignored files**: `git add` refuses an ignored path, and that refusal was reported as "Failed to stage" even though the change had already been written to disk. Accept now recognises the ignored case and skips staging instead of reporting a failure.
- **HTTPS servers are supported**: the connection dialog accepts `https://host:port`, and the API client, the SSE stream, the terminal launch command and the web tab all use the chosen scheme. Previously every request was hardcoded to `http://`, which broke servers behind a TLS proxy.
- **Remote connections open an interactive UI**: connecting to a remote server used to report "Connected to host:port" and leave the user with no way to interact. It now opens a terminal attached to the remote endpoint through `--server`.
- **Previous sessions can be resumed**: a new *Tools → Open Previous OpenCode Session* action lists this project's sessions and resumes the selected one with `--session <id>`. The session list is fetched off the EDT.

### Compatibility

- Built against IntelliJ IDEA 2025.2.4 (`sinceBuild` 252). Supported IDE range is unchanged from 1.2.0.
- Kotlin is pinned to 2.2.20, the version that platform ships, so the plugin never compiles against a stdlib newer than the one it runs on.
- No behaviour change: the full test suite passes unchanged.
