### Improvements

- **No API scheduled for removal.** The terminal was created through `TerminalView`, which carries
  `@ApiStatus.ScheduledForRemoval` in the platform this plugin builds against. It now calls the
  manager that `TerminalView` delegated to, with the same cast the platform performed internally,
  so behaviour is identical and the compatibility floor is unchanged at 2025.2.
