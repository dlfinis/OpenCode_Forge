## 1.2.3

### Fixes

- **No more empty tab in the Terminal tool window.** Creating the terminal registered a tab in the
  Terminal tool window, selected it and opened the window, then moved the widget into the plugin's
  own editor tab. The tab stayed behind, empty, and the window opened on every launch. The plugin
  now removes that tab without disposing the widget and closes the window only when it was the last
  one, so a window holding your own terminals is left alone.

### Improvements

- **Quieter log.** A file that cannot be read while a diff snapshot is captured is no longer logged
  as a warning. The three-level recovery (VFS, disk, LocalHistory) is the designed path, and a
  missing file such as a JCEF cache entry is expected, not an anomaly.

### Compatibility

- Built against IntelliJ IDEA 2025.2.4 (`sinceBuild` 252). Supported IDE range is unchanged.
